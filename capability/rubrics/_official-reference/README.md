# 官方评分标准原文存放处（禁止入库）

这个目录用于**人工对照**官方评分标准（IELTS Band Descriptors 等）。

## 三条硬规矩

1. **禁止提交到版本库** —— `.gitignore` 已排除本目录下所有文件。
2. **禁止进 prompt** —— 官方原文受版权约束，不能直接喂给模型。
3. **禁止进入任何数据集或产物**。

## 正确的做法

需要评分标准时，在 `rubrics/*.yaml` 里写**自述 paraphrase**：

- 维度名 + 每一档 3–5 条**可观测**判据
- 用自己的话描述，不逐字复制官方表述
- 判据要能被文本证据支撑（"错误较多"这类模糊表述不算）

参考现有的 `rubrics/writing-task2.v1.yaml` 与 `rubrics/speaking.v1.yaml`。

## 为什么目录保留但内容为空

保留目录是为了让这条规矩**在文件树上可见**。
如果目录不存在，后人就不知道该把官方原文放哪、也不知道它不能提交。
