# 已知限制

按"会不会误导你"排序，不是按严重程度。

---

## L1. 仓库不含任何题目数据（数据加载模式）

**这是设计，不是缺陷。** 题目由**数据包**提供，通过 `elk load` 装载，
详见 [README §5](../README.md#5-数据从哪来)。

随仓的 `examples/packs/demo-pack/` 是**格式示范**：凭空撰写、1 篇 204 词短文 + 5 题。

它能做什么：证明加载 → 校验 → 索引三步能跑通。
它不能做什么：**它不是练习内容**，样本量毫无意义，不要用它练题或评测。

真实题目来源（任选）：
- 自备数据包：`elk load <路径>`
- 自行抓取：`elk fetch --only reading`（只落本地，不入库）

## L2. 不含 LLM 调用

本项目只负责 prompt 的编译、渲染与留痕。实际调用由你的代码完成：

```python
from elk.build.prompt_loader import render
prompt = render("writing/score", PROMPT_TEXT=..., ESSAY_TEXT=..., FEATURES={...})
response = your_client.complete(prompt)
```

这是刻意的：不绑定厂商、密钥不由库管理、便于离线测试。
0.2 会提供 `examples/llm_adapter.py` 作为参考实现（仍然要你自己填密钥）。

## L3. 写作评分没有可信真值 —— 最重要的一条

我们对三个主流公开数据集做了审计，**四维分数全部不可用**：

| 数据集 | 症状 |
|---|---|
| chillies | GRA 有 31% 是满分（真实应 <1%）；CC 从 8.0 直接跳 9.0，中间无 8.5 |
| btnotpt | overall 可被四维均值 100% 还原 —— 四维由总分反推 |
| hai2131 | 四维两两 r ≈ 0.9；CC/LR/GRA 有 55–62% 取值完全相同 |

交叉证据：chillies 里 TR=9.0 的样本中 overall=6.0 的有 171 篇。

**后果**：任何"对齐真值"的评分器都是在对噪声回归。所以本项目的写作评分 prompt：

- 输出 `band_range`（参考区间）而非精确到 0.5 的单点
- 强制每条判断引用 rubric 中的具体判据（`matched_anchor` 不得为空）
- prompt 开头直接写明"不要声称你的分数等于考官会给出的分数"

我们做过 12 篇的分层盲评：真值 8.0 组我评 6.5，真值 5.0 组我评 5.75——
方向对，但区分度只剩 25%，且我认为我的分数比数据集的更接近实际水平。
在这种情况下输出一个确定数字是有害的。

## L4. 发音在无音频时输出 unavailable

**ASR 转写丢弃全部声学信息**（语调/重音/连读/音准/节奏）。

从 `I think it's very important` 这句转写里，无法判断说话人是 9 分的自然语调
还是 5 分的逐词蹦字——两者转写可能一模一样。

所以 `rubrics/speaking.v1.yaml` 写死了：无音频时 `pronunciation = null`，
`overall` 按 FC/LR/GRA 三项均值算并显式标注。**不许用假造的发音分凑四项均值。**

## L5. 无合成题生成

0.1 的流水线停在"抓取 → 解析 → 校验 → 索引"。

可合法获取的公开阅读题上限约 300 道，这个量级够练手、不够训练。
合成生成是 0.2 的主要内容。

## L6. paraphrase 全空

同义替换（题干表述 ↔ 原文表述）是雅思阅读的核心考察点，
schema 里明确要求"必须在结构化阶段沉淀，不能留到运行时让 LLM 临时编"。

理由：运行时生成有两个问题——每次不一致、无法被 QC 校验。
0.1 尚未填充，0.2 补齐。

## L7. task bank 正文未切段落

分题型样本（task bank）的 passage 目前整篇合成一段，段落标签缺失。
影响 Matching Headings 这类依赖段落标签 A/B/C 的题型。

无障碍大字版（完整真题）的段落切分是正常的（8–10 段，标签 A–J）。

## L8. OCR 对官方手写体无效

官方 sample scripts 的作文正文是**手写扫描件**（JPEG 2000，676×709 像素）。
macOS Vision 在手写体上识别不可用，且 `confidence` 恒为 1.00——
**这个置信度与实际质量完全脱钩，不要信它**。

`src/elk/parse/ocr_official_scripts.py` 保留（对印刷体 PDF 有效），
但对官方样题这条线已暂停。
